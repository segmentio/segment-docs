## title: Lark (Actions) Destination

{% include content/plan-grid.md name="actions" %}

[Lark](https://uselark.ai/?utm_source=segmentio&utm_medium=docs&utm_campaign=partners){:target="\_blank”} provides ultra scalable billing infrastructure with the flexibility to support any pricing model or contract and empowers product teams to own pricing. In addition to Lark's billing engine, it provides powerful hosted surfaces for end customers and makes it seamless to manage feature access, track usage, and handle customer credits.

This destination is maintained by Lark. For any issues with the destination, [contact their Support team](mailto:support@uselark.ai).

## Getting started

1. From your workspace's [Destination catalog page](https://app.segment.com/goto-my-workspace/destinations/catalog){:target="\_blank”} search for "Lark".
2. Select Lark and click **Add Destination**.
3. Select an existing Source to connect to Lark (Actions).
4. Go to the [Lark dashboard](https://dashboard.uselark.ai/admin/api-keys){:target="\_blank"}, create a new API key and copy it.
5. Enter the **API Key** in the Lark destination settings in Segment.
